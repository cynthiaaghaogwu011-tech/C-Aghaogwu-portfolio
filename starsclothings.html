Stars Clothing

Stars Clothing is a modern fashion e-commerce website designed to deliver a clean and engaging online shopping experience.

HTML Tailwind CSS JavaScript Responsive Design
Live Demo Source Code

An editorial fashion e-commerce site built with vanilla JavaScript, designed around a bold, fashion-forward aesthetic. Visitors can browse a hero-driven landing page featuring the "Ori Collection," explore curated categories like Dinner Dresses, Custom Orders, and the Mesh Collection, and scroll through a trending products section with video previews for each item.

Each product includes a name, price, and detail flow, while a working shopping cart, built with localStorage, lets users add items and see real-time confirmation with an "added to cart" message.

The site also includes an email subscription section for exclusive drops and lookbooks, along with standard footer navigation for privacy, terms, and store info. Consistent branding, from the logo mark to the imagery, carries through every page for a polished, boutique feel.
